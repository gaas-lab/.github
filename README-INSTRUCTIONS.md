# Como aplicar o kit

1. Na organização `gaas-lab`, crie ou atualize um repositório público chamado `.github`.
2. Copie `profile/README.md` para `.github/profile/README.md`.
3. Copie a pasta `assets/` para a raiz do repositório `.github` (ajuste o caminho da imagem no README para `../assets/gaas-lab-banner.svg` ou use um caminho raw do GitHub após publicar).
4. Copie `CONTRIBUTING.md` e `.github/ISSUE_TEMPLATE/` para cada repositório em que essas orientações devam valer. Os templates de issue podem ficar no repositório `.github` para compartilhamento padrão da organização.
5. Em Settings da organização, atualize descrição, site, localização e avatar. O SVG serve como referência de arte; se o GitHub não aceitar SVG como avatar, exporte para PNG.
6. Antes de publicar, confirme o link do repositório `ponto.`. A URL `/gaas-lab/ponto` retornou 404 na consulta, embora a organização liste `ponto.` como repositório. Use o link exato da página de repositório.
