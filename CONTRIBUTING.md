# Contribuindo com o gaas.lab

Valeu por querer contribuir! O laboratório trabalha com design, desenvolvimento web e experimentação digital.

## Como contribuir

1. Abra uma issue descrevendo a ideia, dúvida ou problema.
2. Para mudanças de código, faça um fork e crie uma branch com um nome claro.
3. Descreva o que mudou e como validar a alteração.
4. Abra um pull request relacionado à issue, quando houver.

## Diretrizes

- Mantenha o escopo da mudança claro.
- Siga o padrão de código e a estrutura já adotados pelo projeto.
- Atualize a documentação quando necessário.
- Não envie credenciais, tokens, arquivos `.env` ou dados pessoais.
- Use imagens, fontes e outros recursos com licença apropriada.

## Tom do laboratório

Design com intenção. Tecnologia com propósito. Experimentação documentada.
