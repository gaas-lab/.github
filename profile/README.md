## // O laboratório

O **gaas.lab** é um laboratório independente para explorar ideias, criar experiências digitais e transformar problemas em produtos funcionais.

Trabalhamos na interseção entre **design, desenvolvimento web e experimentação**. Cada projeto é uma oportunidade de testar soluções, aprender fazendo e conectar pensamento visual com tecnologia.

> Não é só sobre como parece. É sobre como funciona, como se sente e o que torna possível.

## // Projetos

### 01 — Barbearia Bravio
Sistema web de gestão para barbearias, reunindo agenda, serviços, equipe e acompanhamento financeiro.

- **Aplicação:** [barbearia-bravio.vercel.app](https://barbearia-bravio.vercel.app/)
- **Repositório:** [gaas-lab/barbearia-bravio](https://github.com/gaas-lab/barbearia-bravio)
- **Tecnologias:** React, JavaScript, Vite, CSS e Supabase

### 02 — ponto.
Aplicação web para registrar a jornada de trabalho, acompanhar o saldo de horas e estimar o horário de saída. Inclui calendário, dashboard, histórico, relatórios e exportação de dados.

- **Repositório:** [gaas-lab/ponto.](https://github.com/gaas-lab/ponto.)
- **Tecnologias:** React, Vite, CSS e Supabase

## // Como pensamos

- **Design com intenção.** A forma deve servir à experiência.
- **Tecnologia com propósito.** Código é ferramenta para resolver problemas reais.
- **Experimentação aberta.** Prototipar, testar, aprender e iterar.
- **Documentação honesta.** Explicar o que foi feito, o que está em andamento e o que ainda falta.

## // Stack de trabalho

As ferramentas variam conforme o problema. Nos projetos atuais, exploramos tecnologias web como JavaScript, React, Vite, CSS e Supabase.
